## Lessons for evaluation authors

Use [evaluate-reviewers](../../.agents/skills/custom/evaluate-reviewers/SKILL.md)
for reviewer calibration or corpus evaluation, rather than ordinary branch review.
This authoring recipe and new skill were written after C5's originals were captured.
They are outside frozen G2 reviewer instructions and C5 inputs; C5 did not use them.
A separate [independent preparation-only observation](../../.scratch/ticket-harness/evidence/19-repair-c5-skill-observation.md)
checks invalid-control handling and stage boundaries, with exact tested/final
skill identities and its limited scope retained.
They operationalize existing evaluation/scope requirements without adding an
implementation gate or blanket self-review requirement.

The skill owns the general sequence and pre-dispatch completion condition. These
observed details help choose its bounded preflight and capture work:

1. **Challenge nominal controls at distinct risks.** Contract-supported ground
   truth came from [nested aliases](../../.scratch/ticket-harness/evidence/19-review-spec-h8-observation.json),
   [empty parser operands/deep graphs and finite timeout](../../.scratch/ticket-harness/evidence/19-repair-control-preflight-results.json),
   [filesystem byte/newline decoding](../../.scratch/ticket-harness/evidence/19-repair-path-preflight-results.json),
   [full Git refs versus short names](../../.scratch/ticket-harness/evidence/19-repair-c5-branch-preflight-results.json),
   and [target-local environment/optional Git writes](../../.scratch/ticket-harness/evidence/19-repair-c5-adapter-preflight-results.json).
   These are risk-led examples, not a required every-input/every-platform matrix
   or global set of cases. Assumptions require contract or validation support.
2. **Make capture lossless before dispatch.** Preselect readable prompts and output
   paths, plus lossless raw-byte artifacts separately from display copies. A
   compressed original can preserve exact bytes while a readable copy follows
   normal formatting. [The preserved EOF case](../../.scratch/ticket-harness/evidence/19-repair-stage-check.json)
   shows why later whitespace normalization cannot edit an original. Existing
   frozen copies and the already bounded exception remain unchanged. A prompt
   digest proves identity, not delivery; read-only permission bits describe a
   snapshot, not enforced isolation. Mechanical checks and judgment remain
   separate evidence.
3. **Keep later contradictions visible.** Existing
   [independent whole-ticket Spec audits](../../.scratch/ticket-harness/evidence/19-review-spec-02.md)
   caught invalid controls missed by clean blind trials. Preserve raw reports,
   differing axes, failed checks and adjudications; append corrections and keep
   source-corpus versions distinct from substantive guidance. Source and wording
   changed together in C1→C2, so a wording-only causal claim is unsupported.
   Calibration cannot replace whole-ticket audits or human-owned scope/QA decisions.

committed source, affected callers/owners/writers/readers, save/restore and
invalidation paths, coverage/check evidence and full prior finding keys/history.

are evaluator material, not an answer pattern for new source. Record actual
inspected scope, clean reasoning, omissions and assumptions. Optional suggestions

human-owned.

Substantive source/guidance corrections need identified versions and complete
final-corpus evaluation before success claims. Carry actual unresolved keys,
missing/stale reports and human decisions with the responsible next action.

blockers. Refactors20–24 need their own whole-ticket reviews; M1 feature-start
provenance/all-package cumulative assessment and explicit human QA remain unperformed.
