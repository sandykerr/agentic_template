# Harness design

The [approved spec](../.scratch/ticket-harness/spec.md) is the design authority.
Use the [feature index](../.scratch/ticket-harness/README.md) for implementation
status/eligibility and the [approved plan](../.scratch/ticket-harness/ticket-proposal.md)
for skill changes, remaining slices and human QA milestones, rather than numeric
ticket order. Remaining definitions are published.

Rationale: [ADR-0001](adr/0001-reusable-harness-and-local-integration.md), refined
by [ADR-0002](adr/0002-human-qa-gates-feature-promotion.md).
This compatibility pointer preserves existing references without duplicating the spec.
