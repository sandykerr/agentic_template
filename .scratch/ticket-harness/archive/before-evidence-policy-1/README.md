# Authoring bundle before evidence-policy-1

This byte-preserving snapshot records the canonical authoring files and tickets
immediately before the human-approved evidence-policy amendment. The
[source manifest](source-snapshot.json) maps original repository paths to their
snapshot files, SHA-256 and sizes. Original bytes, labels, numbers and relative
references describe that original location and time; these copies are history,
not current executable planning inputs. Root-relative context for copied files
is retained in the manifest rather than rewritten into their original contents.

Use the [current numbering map](../evidence-policy-numbering-history.md),
[feature index](../../README.md) and [publication approval](../../evidence-policy-approval.md)
for current tickets and gates. The repository handoff and planning reference are
also saved here before their current-pointer updates. This snapshot preserves
authoring records only; evidence, code and original reviews were not relocated.
